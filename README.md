# Project Aether Website

A responsive, static website based on Hasan Ayub's Project Aether presentation.

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `project-aether`).
2. Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder.
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site.

## Important project-status note
This website describes Project Aether as a developing concept. It does not claim that the drone or medical payload has been completed, flight-tested, or approved for medical transport. Medical products have specific storage and handling requirements; any real-world use would require expert oversight, validation, and regulatory compliance.
